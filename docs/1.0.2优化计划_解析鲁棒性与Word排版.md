# Md 转换器 · 1.0.2 优化计划：解析鲁棒性与 Word 排版

> 承接《Md转换器开发计划_买断制Markdown多格式转换工具.md》（v1.0.0 立项）与 v1.0.1 发布（缺陷修复版：思维导图 PNG 导出原写入应用沙箱导致图库不可见，已改为经系统保存弹窗写入相册）。
> 版本基调：v1.0.0 已交付自研 MD 解析器与 JSON/YAML/Word/思维导图四格式输出，离线无上传；v1.0.1 为缺陷修复版。1.0.2 的核心是「让用户敢拿真文档来转」——把解析器的边界情形吃透、把 Word 的中文排版做到能直接交作业/归档，并前移若干 P1 格式。

## 1. 背景与定位

v1.0.0 解析器已声明「未知语法降级为原文保留，绝不丢内容」，但表格对齐、嵌套列表、HTML 块、转义、脚注等中高频语法尚未做系统性回归；Word 输出目前是「能打开」，中文段首缩进、标题编号、表格边框等办公交付细节仍是短板。v1.0.1 已修复思维导图 PNG 导出落盘问题（AlbumImageSaver → showAssetsCreationDialog → 相册），并作为回归项纳入本版验收。1.0.2 把解析鲁棒性与 Word 排版作为双主轴，兼做 HTML/CSV/XMind/图片嵌入前移。

核心原则：**离线、买断、不联网不变；解析器必须零内容丢失；新增格式不引入第三方依赖。**

## 2. 优化项清单

| 编号 | 模块 | 现状（v1.0.1） | 1.0.2 优化 | 验收 |
|---|---|---|---|---|
| D1 | 解析·表格 | 表格支持，对齐/跨行未系统回归 | 补齐对齐符（:--- / ---: / :---:）、单元格内换行、表头缺失默认、嵌套元素退化处理；与解析树 schema 对齐 | 20 份真实笔记表格转 JSON/YAML/Word 无误、不丢列 |
| D2 | 解析·嵌套与转义 | 嵌套列表支持 | 三层以上嵌套、行内 `*` `_` 转义、代码块内 Markdown 不误解析、HTML 块（<div> 等）原样保留或降级 | 边界文档零崩溃、内容零丢失 |
| D3 | 解析·扩展语法 | 基础语法 | 任务列表（- [ ] / - [x]）、脚注、定义列表、分隔线前后空行容错；未知语法一律降级保留 | 扩展语法文档转换可预期，不崩 |
| D4 | 降级不丢内容 | 已声明 | 建立「降级回归测试集」（含所有可能掉内容的语法），CI 级校验 | 回归集 100% 通过，无内容静默丢失 |
| D5 | Word·中文排版 | 标题/正文/列表/表格/代码块基础映射 | 中文段首缩进 2 字符；标题自动多级编号可选；表格边框与表头底纹；代码块等宽+浅底纹；图片嵌入（P1 提前，md 内联图打包进 docx media） | Word 2007+/WPS 双端打开排版专业，可直交 |
| D6 | Word·目录与长文 | 无 | 可选自动目录（基于标题层级）；长文档分页与页眉页码。目录先做静态书签目录（无「更新域」依赖）；若采用域目录，须在双端验证更新域行为后再放开 | 50 页文档生成稳定，目录跳转正常 |
| D7 | 思维导图 | 3 主题 + PNG 导出（v1.0.1 起落盘系统相册）+ .mm/.opml | 交互预览（节点折叠/展开）前移；XMind 原生格式（zip+JSON）前移；主题新增「打印」极简风 | 大文档思维导图渲染流畅、可导入 XMind；PNG 导出回归通过（图库/文件管理可见） |
| D8 | 批量与性能 | 多选批量已支持 | 批量进度条 + 单文件失败隔离（一个失败不影响其余）；大文件（>2MB）以分块读取 + 峰值内存监控为主，保留单遍解析器，流式解析仅作备选方案 | 100 文件批量，失败隔离生效，无 OOM |
| D9 | 格式前移 | P1 计划 | md→HTML 自包含单文件（CSS 内联）；md 表格→CSV 前移，编码固定 UTF-8 with BOM（Excel 中文兼容） | HTML 离线打开样式完整，CSV 编码正确 |

## 3. 风险与对策

| 风险 | 对策 |
|---|---|
| Word 双端差异 | 每次改动在 Word 2007+ 与 WPS 双端实测，回归卡固化 |
| 大文件内存 | 分块读取优先、流式解析备选，监控峰值内存，超阈值降级提示 |
| 图片嵌入隐私 | 仅打包 md 内联的本地/相对路径图片，绝不联网拉取 |

## 4. 非目标（明确不做）

- 不做在线/云转换（离线即卖点）
- 不做账号 / 云同步 / 订阅 / 广告
- 不做反向转换（JSON/YAML→md 留 P2）
- 不做 md→PDF 复杂版面（留 P2）

## 5. 验收总览

- 解析：降级回归集 100% 通过，零内容丢失
- Word：中文排版专业、图片可嵌入、双端实测
- 思维导图：交互预览 + XMind 原生 + 新增主题；PNG 相册导出回归通过
- 批量：失败隔离 + 大文件稳定
- 全链路离线、买断说明与版本号正确（显示 v1.0.2）

## 6. 实施顺序（里程碑批次）

沿用主计划方法论：每批次一提交、自研解析/生成零第三方依赖、黄金 dump 对账、模拟器全量用例回归。测试基建复用 ohosTest 13 套用例与 scripts 对账脚本，本版预计新增用例 ≥40（D1-D4 回归集 + 各格式新特性）。

| 批次 | 内容 | 对应优化项 | 主要产出 |
|---|---|---|---|
| T1 | 解析鲁棒性 | D1-D4 | MdParser/MdInlineParser 边界补齐 + 降级回归测试集（新用例文件） |
| T2 | Word 排版 | D5-D6 | DocxOut 中文缩进/编号/边框/底纹/图片嵌入 + 静态书签目录 + docx_check 扩展 |
| T3 | 思维导图 | D7 | MindmapPreviewPage 折叠交互 + XmindOut（zip+JSON） + 打印主题 + 回归 |
| T4 | 批量与性能 | D8 | BatchConvertPage 进度条 + 失败隔离 + FileIoUtil 分块读取 |
| T5 | 格式前移 | D9 | MdHtmlOut（CSS 内联单文件） + MdCsvOut（UTF-8 BOM） + 用例 |
| T6 | 收尾 | 全部 | 版本号 1.0.2、验收总览核对、执行记录归档、debug/release 双构建绿 |

依赖关系：T1 是 T2/T5 的前置（Word/HTML/CSV 均消费解析树，解析 schema 变更需先行）；T3/T4 相对独立可并行；T6 收口。
